# Maintaining the EduCloud ecosystem

Read `CLAUDE.md`, `docs/development/PILOT_PROTOCOL_V1.md` and `CONTRIBUTING.md`.
The shared protocol is a minimum; component-specific authority and licenses apply.
Start at `README.md` for current pilot status and `docs/pilot/INTEGRATION.md` for
how the parts connect. `SYSTEM.md` remains the authority for shared contracts.

Keep acceptance evidence in `pilot/readiness.json` separate from automated public
GitHub observations in `pilot/status.json`. Only reviewed evidence can change
readiness. Do not edit the generated README status block by hand. Do not stage
other chats' files or promote local synthetic results into student deployment.
