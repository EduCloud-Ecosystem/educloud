# INFO 511 classroom pilot checklist

Updated November 18, 2026. The first deliverable is a student starter for the NHANES assignment. Students should be able to run the notebook, explain their join, use optional help, save their work, and find their submission receipt.

Use this page to decide what to build next under [EduCloud #56](https://github.com/EduCloud-Ecosystem/educloud/issues/56). The [student-release specification](../specs/classroom-student-release-v1.md) defines acceptance. The [reviewed readiness record](../../pilot/readiness.json) records release decisions. Current qualification covers local instructor testing. Student admission is closed.

## Promising features and approaches

| Priority | Learner experience | Evidence today | Smallest useful next step |
|---|---|---|---|
| Use in the first assignment | Predict the columns and what one row represents, then explain missing readings versus unmatched participants from memory. | Studio already offers a prediction checkpoint. Local lecture notes include static recall prompts. The checkpoint records presence. | Add one short recall-and-check prompt to the starter. Review the independent explanation with the instructor rubric. The exercise works with AI disabled. |
| Validate for the pilot | Ask for a hint about the selected cell, see what will be shared, and keep working through expiry or outage. | A prepared question passes the merged workflow. The provider guard accepts fixed inputs. | Test realistic misconceptions against the approved student route and an equivalent no-AI path. Keep answers, grades, and submission under their existing authorities. |
| Evaluate during usability testing | Find Run, Save, Tutor and lecture notes through optional contextual cues, a replayable tour and a diagram with a text equivalent. | These are implemented on the separate Waypoint prototype. | Observe a first-time tester locating each control unaided, then using the guide when stuck. Check keyboard dismissal, focus return and screen-reader instructions. Integrate the smallest piece that resolves an observed problem. |
| Evaluate after course content is available | Jump from an NHANES concept to the relevant lecture passage in the notebook. | The prototype has three static topic anchors with illustrative times. Actual recording alignment is open. | Start with instructor-approved notes. For one captioned lecture, verify each timestamp against the recording and provide a usable transcript when playback is unavailable. |

These priorities adapt LongCut’s navigation, Clicky’s contextual guidance and the recall exercise associated with Wispr Flow. Full LongCut hosting, cloud dictation, the desktop companion and Gistr accounts add service and data flows beyond the first assignment. Keep System One typed decisions in shadow evaluation until they show useful accuracy, cost and fallback behavior on classroom cases. Wayfare mobile, Inquiry Commons and research benchmarking have their own acceptance paths.
