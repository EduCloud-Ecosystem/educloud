## Execution discipline

Root owns plan, source release, integration, independent review, PR push and merge.
One source owner per component; old accepted worktrees frozen. The existing Outfitter owner owns Go; the existing Waypoint owner owns its
subsequent integration; a separate reviewer independently reviews immutable
critical source/evidence. Root initially reads contracts and
interfaces; no new source author starts before exact scope/base/worktree claim.
Do not implement J2 against an invented or unqualified helper interface.

Serial local compile/targeted work requires coherent copied source inventory,
exact commands/finite deadline and root reservation. No concurrent local suites.
Default fail-fast, retain failures and unknown historical causes; no timing-only
retry, timeout inflation, omitted tests, reset liability or allowance renewal.
The 15-minute configured Outfitter job and all original assertions stay intact;
new coverage must fit honestly or produce a reviewed bounded coverage plan before
execution. Root reviews final source and joblog/artifact evidence before merge.
